  (b) lawvere_diagonal_fixed_point (`proofs/afnt-alpha-id/lawvere_fp.vr`):
      Given (Obj, Hom, comp, T, A, ProdAA, Y, diag, eval_map, f, pair_aa, a0)
      and equational path hypotheses:
        h_assoc1  : (pair_aa ; eval_map) ; f = pair_aa ; (eval_map ; f)
        h_diag_pt : pair_aa = a0 ; diag
        h_assoc2  : (a0 ; diag) ; (eval_map ; f) = a0 ; (diag ; (eval_map ; f))
        h_surj    : pair_aa ; eval_map = a0 ; (diag ; (eval_map ; f))
      derives Id(Hom T Y, (pair_aa ; eval_map) ; f, pair_aa ; eval_map)
      by J-transport / identity induction:
        rewrite(h_assoc1); induction h_diag_pt; rewrite(h_assoc2);
        rewrite < h_surj; reflexivity.

  (c) dual_afnt_route1a_retraction_refutation (`proofs/afnt-alpha-id/route1a_retraction.vr`):
